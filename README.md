# Канский драматический театр

- `npm run dev` — разработка
- `npm run build && npm run preview`, затем `npm run check` — проверка перед сдачей (отчёт в check-report/)
- Цвета/шрифты — только в `src/styles/tokens.css` (из DESIGN.md)
- Заявки в Telegram: в Netlify → Environment variables задать `TG_TOKEN`, `TG_CHAT`
- Перед сдачей: положить `public/og.jpg` (1200×630), проверить реквизиты в privacy.html
